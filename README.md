# Mahjong Scoreboard (iOS)

Mahjong Scoreboard is an iOS app designed to simplify score tracking during
Japanese riichi mahjong games. It was built to replace handwritten scorekeeping
with something faster, clearer, and less error-prone during live play.

The app is optimized for in-person games, prioritizing speed and clarity over
visual complexity.

## Features
- Score tracking for multiple players
- Riichi declaration handling
- Support for ron, tsumo, and multiple ron
- Fu calculation and score breakdown
- Dice rolling and round timer utilities
- Persistent score state across hands

## Motivation
The project began after watching a friend manually record scores during games,
which quickly became tedious and prone to mistakes. Rather than relying on
paper or overly complex apps, I wanted a focused tool that handled scoring
accurately while staying out of the way of gameplay.

Over time, additional features were added organically in response to real
in-game needs.

## Tech
- Swift
- SwiftUI
- Xcode

## Design Notes
- Built for quick interaction during live games
- Emphasis on readable layouts and clear state changes
- Designed primarily for personal use on a single device

## Status
Personal utility project. Actively used during games and incrementally improved
as new needs arise. Shared here as a practical example of solving a real-world
problem with software.
